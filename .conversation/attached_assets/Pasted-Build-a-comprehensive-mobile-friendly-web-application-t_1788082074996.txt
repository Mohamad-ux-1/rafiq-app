Build a comprehensive, mobile-friendly web application to track weight gain, nutrition, and home workouts.

Tech Stack: React.js, Vite, Material UI (MUI), and Chart.js/Recharts. Use LocalStorage for data persistence. The UI must be in Arabic with RTL (Right-to-Left) support.

Core Features & Tabs:

Tab 1: Dashboard & Analytics (Progress Evaluation)

A dashboard showing daily, weekly, and monthly progress.

Weekly Weight Chart: Line chart tracking weight progress from 60 kg to the target (67 kg).

Progress Evaluation: An automated feedback message based on weekly weight input (e.g., "Great progress, keep it up!" if gained 0.5-1kg, or "You need to increase calories slightly!" if gained less than 0.3kg).

Tab 2: Daily Habit & Calorie Tracker

Habits Checklist: Checkboxes for (Evening high-calorie shake, Added Olive Oil/Tahini, Pocket Snack, Completed Workout).

Manual Calorie Entry: An input field to manually add calories directly to the daily total.

Calorie Progress Bar: A visual progress bar showing calories consumed vs. the daily goal (2800 kcal).

Tab 3: AI Food Scanner & Estimator (Smart Tab)

An interface to input food (either by typing the food name or simulating an image upload).

API Integration: Integrate a free nutrition API (like Edamam, CalorieNinja, or a mock Gemini/OpenAI API call) to estimate calories based on text input or simulated image recognition.

Requirement: It should return an estimated calorie count (e.g., "1 plate of rice = ~250 kcal") with an option to instantly add these calories to the "Daily Calorie Tracker" in Tab 2. It does not need to store the image permanently.

Tab 4: Economical Diet Guide

Static reference cards displaying high-calorie, cheap alternatives (e.g., Olive oil, Peanuts, Local Yogurt, Oats).

Notifications & Reminders:

Web push notifications reminding the user daily (9:00 PM for the shake) and weekly (Saturday morning for weight logging).

Design Requirements:
Clean, modular, and optimized for mobile devices. Use modern React hooks and standard ES6 syntax so the codebase is easy to read, expand, and maintain.
